Visualisation

Muscle Cost

The diagram below shows the muscular effort involved in the simulation run. A different color is used for each click on an element along the click path (see legend). A solid line represents the hands movement directly from the previously clicked element towards the next target element. The numbered vertical dotted lines mark the point at which a new element is clicked. A diamond symbol in the color of the corresponding click marks the moment of contact with that element. The value in the box below each line indicates the average muscular effort required to click that element.

Finger Trajectory

The following diagram shows the physical X/Y movement of the finger during the simulation run. Here too, a different color is used for each click on an element along the clickpath, though these colors correspond to those used in the other diagrams. A solid line represents the hands movement directly from the previously clicked element to the next target element. The start of this movement is marked with a circle and the end (contact with the element) with a diamond symbol.

Click Timeline

The diagram below shows the respective points of contact between the simulated finger and the corresponding simulated element from the clickpath. To enable the selected clickpath to be followed step by step, small thumbnails of the actual Figma elements are also displayed. With many clicks close together in time, these thumbnails may shrink to fit - hover over one to see it enlarged.
